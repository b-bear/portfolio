Animation & FX for WordFlow ​

Software: Photoshop, Unity ​

WordFlow is a relaxing word search puzzle game where players solve engaging levels and journey through a variety of beautiful new locations. Engaging core game FX gave players immediate feedback, while fun and imaginative hint animations strengthened the hint themeing and individuality, rewarding players for using coins.

Subtle animations using Unity particle effects and shaders brought the backgrounds to life, enhancing the atmosphere while maintaining performance and keeping asset sizes minimal.
